# Navigation

## Purpose
Define navigation patterns that stay branded while remaining easy to scan and operate.

## Patterns
- Top navigation
- Mobile menu
- Section tabs
- Breadcrumbs

## Typography Baseline
- Labels should use readable body/headline families.
- Avoid decorative display fonts in persistent navigation.

## Interaction Baseline
- Clear active state
- Clear focus state
- Predictable hover behavior

## Accessibility Baseline
- Keyboard navigation must be supported.
- Current page or section should be clearly indicated.
