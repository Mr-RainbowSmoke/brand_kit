# Forms

## Purpose
Define form control behavior and styling guardrails.

## Controls
- Text input
- Text area
- Select
- Checkbox
- Radio
- Toggle

## Typography
- Label family: Transat
- Helper and validation text: Transat or Le Havre Rounded
- Avoid decorative display fonts in form controls

## Validation States
- Default
- Focus
- Success
- Error
- Disabled

## Error Pattern
- Error state requires icon or label plus message text.
- Do not indicate validation status by color alone.

## Accessibility Baseline
- Labels must be visible and associated with controls.
- Focus indicator must be visible on every control.
- Required fields should be explained explicitly.
