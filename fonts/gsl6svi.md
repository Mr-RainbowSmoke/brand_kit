## CSS Usage Examples

### Using Font Families Directly

```css
/* Le Havre Rounded */
h1 {
  font-family: "le-havre-rounded", sans-serif;
  font-weight: 700;
}

/* Transat */
body {
  font-family: "transat", sans-serif;
  font-weight: 400;
}

/* Rig Solid Bold Fill */
.headline {
  font-family: "rig-solid-bold-fill", sans-serif;
  font-weight: 700;
}

/* Elliott's Blue Eyeshadow */
.creative-header {
  font-family: "elliotts-blue-eyeshadow", sans-serif;
  font-weight: 400;
}

/* Perec Scripte Deco */
.elegant-text {
  font-family: "perec-scripte-deco", sans-serif;
  font-weight: 400;
}
```

### Using Typekit Classes

```html
<!-- Le Havre Rounded -->
<h1 class="tk-le-havre-rounded">Headline Text</h1>

<!-- Transat -->
<p class="tk-transat">Body text goes here</p>

<!-- Rig Solid Bold Inline -->
<div class="tk-rig-solid-bold-inline">Creative Display</div>

<!-- Elliott's Jigsaw Dropshadow -->

<!-- Perec Scripte Deco -->

```

## Font Loading Performance

All fonts in this project support:
- **WOFF2** (modern browsers - smallest file size)
- **WOFF** (fallback for older browsers)
- **OpenType** (additional fallback)

The fonts use `font-display: auto` which means the browser decides the best loading strategy.
