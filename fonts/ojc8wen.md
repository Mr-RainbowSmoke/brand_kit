## Font Loading Performance

All fonts in this project support:
- **WOFF2** (modern browsers - smallest file size, best performance)
- **WOFF** (fallback for older browsers)
- **OpenType** (additional fallback)

The fonts use `font-display: auto` which allows the browser to determine the best loading strategy based on network conditions.
