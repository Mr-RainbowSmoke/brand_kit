# Web Playbook

## Goal
Apply RAINBOWSMOKE branding consistently across websites and landing pages.

## Structure Baseline
- Hero with strong but readable hierarchy
- Section rhythm with clear heading levels
- Distinct call-to-action zones

## Typography Baseline
- Follow ../visual-system/TYPOGRAPHY_SYSTEM.md
- Body readability takes priority over display impact

## Color Baseline
- Use approved palette combinations only
- Preserve contrast in CTA and navigation areas

## Asset Usage
- Prefer SVG marks where possible
- Keep profile and glyph marks within approved clear-space zones

## Accessibility Baseline
- Keyboard navigation required
- Focus states required
- Contrast at AA minimum
