# Print Playbook

## Goal
Keep printed materials visually consistent with digital identity while preserving legibility.

## Use Cases
- Posters
- One-pagers
- Event collateral
- Partner handouts

## Typography Baseline
- Preserve hierarchy and avoid overcrowding display fonts.
- Keep body content in highly readable families.

## Color Baseline
- Use approved palette values and verify print-safe rendering.
- Keep key text/background combinations high contrast.

## Production Baseline
- Maintain safe margins and bleed expectations per vendor spec.
- Validate logo clear space before export.

## Print Production Checklist
- [ ] Correct print dimensions and bleed are set.
- [ ] Typography hierarchy remains readable at print size.
- [ ] Canonical logo/mark assets are used.
- [ ] Color output is validated for print-safe rendering.
- [ ] Contrast remains strong for key callouts and body content.
- [ ] Final output exported in vendor-required format.

## Starter Layout Template
1. Header band: brand mark plus headline.
2. Core message section: concise value statement and supporting points.
3. Proof or highlight strip: creator/community highlight.
4. Action footer: CTA, URL, or contact path.
