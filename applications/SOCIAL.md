# Social Playbook

## Goal
Keep social content expressive, fast to produce, and clearly on-brand.

## Formats
- Square post (1080x1080)
- Story/reel (1080x1920)
- Wide video cover (1920x1080)

## Typography Baseline
- One dominant headline family per graphic
- Keep support text minimal and legible
- Use accent fonts only as supporting detail

## Color Baseline
- Prioritize high-contrast combinations for mobile viewing
- Keep blue-forward identity visible across recurring content

## Content Pattern
- Hook
- Value statement
- Action cue

## Accessibility Baseline
- Avoid tiny text on mobile-first formats
- Do not rely on color-only meaning in charts or labels

## Publishing Checklist
- [ ] One clear hook in first line.
- [ ] One primary visual hierarchy (headline first, support second).
- [ ] Approved asset files only from canonical set.
- [ ] Text remains readable at thumbnail size.
- [ ] CTA is explicit (comment, join, watch, share).

## Starter Content Template
1. Hook: one high-energy line.
2. Value: one sentence that explains what the audience gets.
3. CTA: one direct action phrase.
