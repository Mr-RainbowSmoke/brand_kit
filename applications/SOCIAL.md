# Social Playbook

## Goal
Keep social content expressive, fast to produce, and clearly on-brand.

## Required Asset Variants

| Format | Dimensions | Use case |
|---|---|---|
| Square post | 1080 × 1080 px | Feed post, community update |
| Story / reel | 1080 × 1920 px | Stories, short-form video |
| Wide video cover | 1920 × 1080 px | Channel banner, video thumbnail |
| Profile mark | 400 × 400 px | Platform profile image |

## Safe Zones

| Format | Safe zone (center) | Avoid zone |
|---|---|---|
| Square post (1080×1080) | 900×900 px centered | 90px border on all sides |
| Story / reel (1080×1920) | 1080×1420 px (top-center) | Bottom 300px (interaction bar), top 250px (profile row) |
| Wide video cover (1920×1080) | 1600×900 px centered | 160px border on all sides |

## Typography Baseline
- One dominant headline font per graphic (Omnes Narrow Black or Rig Solid for high-impact)
- Support text minimal and legible: Transat or Le Havre Rounded
- Accent fonts (Elliott's, Sketchnote) used as single supporting detail only
- Minimum readable size at final export: 28px equivalent for primary text

## Color Baseline
- Prioritize high-contrast combinations for mobile viewing
- Blue-forward (Royalty) identity visible across recurring content series
- Cotton Candy used for community, celebration, or seasonal moments
- Pride rainbow used as graphic device — not as a background fill for text

## Content Pattern
- **Hook**: one high-energy or curiosity-driving line
- **Value**: one sentence — what the audience gets or why it matters
- **Action cue**: one direct verb phrase — Join, Watch, Drop a comment

## Copy Tone Variant
- Expressive and community-first — personality over polish
- Short sentences, direct address, energy-forward
- Captions should still be readable without the image (accessibility)
- Hashtags: use sparingly, end of caption, max 5 on-platform hashtags

## Do / Don't

| Do | Don't |
|---|---|
| Keep primary text inside the safe zone | Place key text in the avoid zone (edges and bottom on stories) |
| Use one dominant display font per graphic | Mix Omnes Narrow and Rig Solid on the same post |
| Lead caption with a strong first sentence | Open with a hashtag or mention |
| Use approved asset files only | Stretch or recolor marks to fit a post |
| Include alt text on all static posts | Publish with no alt text |

## Accessibility Baseline
- Write captions that convey the same message as the visual (not "check the image")
- Avoid tiny text on mobile-first formats (min 28px equivalent at final size)
- Do not rely on color-only meaning in charts or category labels

## Publishing Checklist
- [ ] Format and dimensions match intended platform placement
- [ ] All key text is inside the safe zone
- [ ] One clear hook in first caption line
- [ ] One primary visual hierarchy (headline first, support second)
- [ ] Approved canonical asset files only
- [ ] Text readable at thumbnail size
- [ ] CTA is explicit and action-oriented
- [ ] Alt text written for static graphics

## Starter Content Template
1. Graphic: hook headline in Omnes Narrow Black or Rig Solid; supporting line in Transat
2. Caption line 1: strong hook (no hashtags)
3. Caption line 2: one value sentence
4. Caption final line: one CTA verb phrase
5. Hashtags (max 5) at caption end
