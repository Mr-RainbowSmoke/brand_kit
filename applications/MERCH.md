# Merch Playbook

## Goal
Apply brand marks and typography consistently across physical merchandise.

## Use Cases
- Apparel (tees, hoodies, hats)
- Stickers (die-cut, holographic, standard)
- Badges and pins
- Event items (lanyards, tote bags, cups)

## Required Asset Variants

| Asset | Format | Notes |
|---|---|---|
| Primary mark (light version) | EPS / vector PDF | For dark-base apparel and items |
| Primary mark (dark version) | EPS / vector PDF | For light-base apparel and items |
| RS glyph (standalone) | EPS / vector PDF | For small placements (badges, pins, hat embroidery) |
| Full-color mark | EPS / vector PDF | Event or premium items with full color output |

## Placement Zones

| Item | Placement | Size guidance |
|---|---|---|
| Tee (front center) | Center chest, 25–30cm wide | Dominant; full mark or statement design |
| Tee (back) | Upper back yoke or full back | Glyph or short phrase; respect seam margins |
| Hoodie (front) | Left chest or center chest | Full mark at 10–15cm for left chest |
| Hat (front panel) | Centered on crown | Glyph or compact mark only; max 7cm wide |
| Sticker | Full bleed to die-cut edge | 3mm bleed; use vector source |
| Badge / pin | Face area | Glyph or compact mark; min 2cm diameter |
| Tote (front) | Center panel | Full mark or campaign graphic; 20–25cm |

## Mark Usage
- Use canonical mark files from [asset-library/ASSET_INDEX.md](../asset-library/ASSET_INDEX.md)
- Do not stretch, skew, or redraw marks
- Do not place the mark over seams, zippers, or buttons
- Light marks on dark materials; dark marks on light materials — never the same version on both without testing

## Color Baseline
- Test palette colors against material base color before production run
- Pride rainbow works as a graphic motif or stripe; avoid as a repeating pattern that obscures mark legibility
- For single-color production (screen print, embroidery): use RS glyph or compact mark in high-contrast single ink

## Typography Baseline
- Statement items: Omnes Narrow Black or Rig Solid Bold for high-impact phrases (1 per item)
- Informational copy (event name, date, URL): Transat Regular at legible size
- Keep copy minimal — one primary message max per item

## Do / Don't

| Do | Don't |
|---|---|
| Use vector source files for all production handoffs | Export the mark from a low-res raster for embroidery or screen print |
| Test the mark on both dark and light material color before ordering | Assume digital mockups match actual fabric or material output |
| Keep mark clear of seams, buttons, and problem placement areas | Center a mark directly over a chest pocket or zipper |
| Provide both light and dark mark variants in the handoff kit | Send only one mark version and ask the vendor to adapt it |
| Order a production sample before full run | Commit to a full production run without a physical proof |

## Merch Readiness Checklist
- [ ] Canonical mark files selected (light and dark versions)
- [ ] Placement respects zone guidance and avoids seams/problem areas
- [ ] Typography is readable at real-world print scale
- [ ] Palette selection tested against material base color
- [ ] No deprecated duplicate mark variants in handoff
- [ ] Physical production sample ordered before full run

## Starter Merch Template
1. Primary mark placement: dominant surface at correct zone size
2. Secondary element: RS glyph or supportive motif (optional)
3. Optional copy line: short, high-impact phrase in Omnes Narrow Black
4. Variant set: dark-base and light-base production mock for vendor review
