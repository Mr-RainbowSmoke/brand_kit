# Merch Playbook

## Goal
Apply brand marks and typography consistently across physical merchandise.

## Use Cases
- Apparel
- Stickers
- Badges
- Event items

## Mark Usage
- Use canonical mark files from ../asset-library/ASSET_INDEX.md.
- Do not stretch, skew, or redraw marks.

## Typography Baseline
- Use display type selectively for statement items.
- Keep informational copy readable at real-world viewing distance.

## Color Baseline
- Use approved palette combinations and test on material color.
- Preserve contrast for legibility and brand recognition.
