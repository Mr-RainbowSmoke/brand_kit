# Merch Playbook

## Goal
Apply brand marks and typography consistently across physical merchandise.

## Use Cases
- Apparel
- Stickers
- Badges
- Event items

## Mark Usage
- Use canonical mark files from ../asset-library/ASSET_INDEX.md.
- Do not stretch, skew, or redraw marks.

## Typography Baseline
- Use display type selectively for statement items.
- Keep informational copy readable at real-world viewing distance.

## Color Baseline
- Use approved palette combinations and test on material color.
- Preserve contrast for legibility and brand recognition.

## Merch Readiness Checklist
- [ ] Canonical mark files selected from ../asset-library/ASSET_INDEX.md.
- [ ] Placement preserves clear space and avoids seams/problem areas.
- [ ] Typography remains readable at real-world print scale.
- [ ] Palette selection tested against material base color.
- [ ] No deprecated duplicate variants included in handoff.

## Starter Merch Template
1. Primary mark placement: front or dominant surface.
2. Secondary element: RS glyph or supportive motif.
3. Optional copy line: short, high-impact phrase.
4. Variant set: dark-base and light-base production mock.
