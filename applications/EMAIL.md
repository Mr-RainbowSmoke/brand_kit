# Email Playbook

## Goal
Keep outbound communication clear, branded, and consistent across newsletter and campaign formats.

## Structure Baseline
- Branded header
- Clear lead section
- Single primary action
- Supporting blocks with predictable hierarchy

## Typography Baseline
- Body clarity over stylistic novelty
- Limit decorative display type in email clients

## Color Baseline
- Use tested high-contrast pairings
- Reserve high-intensity accents for key calls to action

## Tone Baseline
- Follow ../verbal-system/VOICE_AND_TONE.md
- Keep copy concise and purpose-driven

## Accessibility Baseline
- Link text must be descriptive
- CTA labels must be specific
- Maintain AA contrast and mobile readability

## Email QA Checklist
- [ ] Subject line is specific and on-brand.
- [ ] Preheader supports the primary message.
- [ ] One clear primary CTA is present.
- [ ] Typography remains readable across major clients.
- [ ] Canonical assets only (no deprecated duplicates).
- [ ] Links are descriptive and action-oriented.

## Starter Message Template
1. Lead: one line that frames value.
2. Body: two to three short blocks with clear hierarchy.
3. CTA: one primary action plus one optional secondary link.
