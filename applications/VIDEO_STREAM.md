# Video And Stream Playbook

## Goal
Ensure overlays, intros, and stream visuals remain recognizable and legible in motion.

## Use Cases
- Stream overlays
- Intro/outro slates
- Lower thirds
- Highlight edits

## Typography Baseline
- Prioritize legibility for live viewing distances
- Keep decorative display type to title cards or intros
- Use clear hierarchy for speaker name and status text

## Color Baseline
- Use approved high-contrast pairings for overlays on variable footage.
- Keep brand-blue presence visible without reducing label readability.

## Motion Baseline
- Use smooth, non-distracting transitions
- Avoid high-frequency flashing
- Respect reduced-motion alternatives for digital products

## Asset Baseline
- Use canonical overlays and glyphs from ../asset-library/ASSET_INDEX.md

## Accessibility Baseline
- Ensure sufficient contrast on dynamic backgrounds
- Keep lower-third text in readable size bands

## Stream Overlay Checklist
- [ ] Nameplate and status text use readable type sizes.
- [ ] Overlay marks use canonical SVG assets.
- [ ] Motion effects are smooth and non-distracting.
- [ ] Scene transitions avoid flash-heavy behavior.
- [ ] Important labels remain readable on bright and dark footage.

## Lower Third Template
1. Primary line: creator or segment name.
2. Secondary line: short context or action prompt.
3. Optional tag: live status, event tag, or campaign marker.
